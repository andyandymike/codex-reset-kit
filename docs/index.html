Fail-closed by design

Safety is the product.

01

No token handling

Uses the documented Codex App Server. It never reads auth files, cookies, or raw tokens.

02

Explicit confirmation

Read-only inspection is separate from redemption, which requires a precise selector and confirmation.

03

Verifiable outcomes

Idempotency keys and distinct proof levels make ambiguous or partial results visible instead of guessing.

Quick start

Local tools, minimal setup.

You need Node.js 22 or newer, a local Codex CLI, and a compatible signed-in ChatGPT-backed account. Development dependencies are only needed when building from source.

1

Install

npm install --global codex-reset-kit
2

Inspect without consuming

codex-reset doctor
codex-reset list --json
3

Redeem only when intended

codex-reset redeem --credit-id <opaque-id>

Open development

Tested without touching a real account.

The automated suite uses a fake App Server fixture and contains no live-redemption path. Review the implementation, safety model, and test cases on GitHub.
