Three explicit steps

Inspect the count. Bind one target. Confirm locally.

01

List available credits

Read the authoritative count and whatever supported detail rows the service makes available.

02

Choose the exact target

Select by credit ID, earliest expiry, or a calendar date in your own timezone.

03

Redeem and verify

Use an attempt-specific local terminal phrase, then get exact, partial, or unknown evidence instead of a guess.

Quick start

Local tools, minimal setup.

You need Node.js 22 or newer, a local Codex CLI, and a compatible signed-in ChatGPT-backed account. Development dependencies are only needed when building from source.

1

Build from source

npm ci --ignore-scripts
npm run check

The npm package is not published yet.

2

Inspect without consuming

node bin/codex-reset.js doctor
node bin/codex-reset.js list --json
3

Redeem only in your terminal

node bin/codex-reset.js redeem \
  --credit-id <opaque-id>

Open development

Tested without touching a real account.

The automated suite hard-blocks unmarked App Server executables and uses only a stateful fake fixture. The Skill can inspect and prepare, but never performs the commit.
