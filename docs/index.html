The missing mobile action

At your desk, use Codex. Away from it, use Remote.

Codex already lets you trigger a reset when you are sitting at the computer. The pain starts after you leave: the mobile app can continue and steer the task through Remote, but it does not give you that same direct reset control.

Codex Reset Kit adds that one narrow capability. It runs on the paired computer, uses the computer's existing Codex sign-in, and brings the exact approval back to your phone. It is not a generic remote-control daemon and it never opens a network port.

Three deliberate steps

Inspect on the host. Approve on the phone. Verify the result.

01

Find one exact credit

Select by opaque ID, unique earliest expiry, or calendar date plus an explicit IANA time zone. Ambiguity stops the flow.

02

Approve the bound action

Codex marks the tool destructive. A second form shows the account fingerprint, credit, and expiry and requires an attempt-specific phrase.

03

Send once and prove it

The host rejects drift, persists one idempotency key, sends once, then reports verified, partial, or unknown evidence instead of guessing.

Quick start

Install once on the computer. Use it later from your phone.

The host needs Node.js 22+, current Codex and ChatGPT desktop, and a compatible signed-in personal ChatGPT account. Contributors need the repository toolchain; ordinary users do not.

1

Add the GitHub marketplace

codex plugin marketplace add andyandymike/codex-reset-kit

Restart ChatGPT desktop, open Plugins, choose the new marketplace, and install Codex Reset Kit. Codex CLI users can install it from /plugins. Keep approvals_reviewer = "user" on this host so a person reviews the irreversible tool call.

Before leaving, start a new desktop task and ask Use $redeem-codex-reset to check whether this computer is ready for a phone Remote reset. The preflight is read-only and verifies the host, local journal readiness, and the required phone confirmation form.

2

Pair ChatGPT Remote

Keep ChatGPT desktop awake and online, pair the mobile app to that host, and start a new Codex task after installing the plugin.

3

Ask from the phone

Use $redeem-codex-reset to use the
reset expiring on 2030-08-01 in
Asia/Tokyo.

Fail closed by design

Real consequence. Fake-only automated proof.

The test suite blocks unmarked App Server executables and completes the full remote MCP flow against a stateful fake. It proves that the consume request is absent before the bound form response, uses the exact selected credit once, and preserves same-attempt recovery. CI never signs into ChatGPT and never consumes a real reset.
